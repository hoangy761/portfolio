# 0xWhyZi | DeFi CV

English portfolio CV for **Bùi Hoàng Ý** (`0xWhyZi`), built with Next.js App Router + Tailwind.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Edit [`src/data/cv.ts`](src/data/cv.ts) to update copy, metrics, and links without touching layout.

## Design notes

Visual direction: **Precision Terminal Editorial** (cool teal-slate, grid atmosphere, Syne + IBM Plex). Design constraints informed by [huashu-design](https://github.com/alchaincyf/huashu-design) (local clone under `.skills/`, gitignored).
